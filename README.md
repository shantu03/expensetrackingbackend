## 🚀 Tech Stack & Deployment

This project follows a decoupled full-stack architecture, ensuring high scalability, serverless database efficiency, and seamless continuous deployment.

* **Frontend:** Deployed on **Vercel** for fast, edge-optimized UI delivery.
* **Backend:** Hosted on **Railway**, managing the application logic, API routing, and server operations.
* **Database:** Powered by **Neon**, utilizing a serverless **PostgreSQL** instance for flexible and scalable data storage.

All components are fully integrated, providing a seamless end-to-end user experience with automated deployment workflows.
